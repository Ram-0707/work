# 웹툰 작업량 관리

웹툰 프로젝트의 작업량(컷)을 캘린더에서 관리하는 웹 앱입니다.
서버 없이 동작하며, 데이터는 브라우저의 localStorage에 저장됩니다.

## 기능

- **프로젝트별 색상 구분** — 여러 작품을 한 캘린더에서 동시에 관리
- **작업일 직접 선택** — 연속일이 아니어도 하루씩 눌러 지정 (Shift+클릭으로 범위 선택)
- **자동 분배** — 총 컷수를 작업일 수만큼 균등하게 나눠 하루 목표량 산출
- **자동 재계산** — 그날 실제로 한 컷수를 입력하면, 남은 컷수를 남은 작업일에 다시 분배
- **콘티 모드** — 켜면 초안과 클린업을 각각 총 컷수만큼 따로 기록 (60컷 → 초안 60컷 + 클린업 60컷)
- **드래그로 일정 이동** — 연달아 붙은 작업일 묶음을 통째로 다른 날짜로 이동 (Alt+드래그: 하루만)
- **마감일 지정** — 캘린더 날짜를 눌러 지정
- **연속 스크롤 캘린더** — 달 단위로 페이지가 끊기지 않고 주 단위로 계속 이어짐
- **주간 체크리스트** — 캘린더 맨 오른쪽 칸에 그 주에 할 일을 적고 체크
- **백업 내보내기 / 불러오기** — 전체 데이터를 JSON 파일로 저장하고 복원
- **한눈에 보기** — 날짜마다 프로젝트별 `목표 / 작업` 컷수를 함께 표시

## 계산 방식

```
하루 목표량 = 남은 컷수 ÷ 실적 미입력 작업일 수
```

- 실적을 입력하지 않은 날은 모두 같은 목표량을 나눠 갖습니다. (50컷 / 5일 → 매일 10컷)
- 실적을 입력하면 그만큼 남은 컷수에서 빠지고 남은 날의 목표량이 다시 계산됩니다.
- 이미 입력한 날의 목표량은 그날까지 남아 있던 컷수를 그때 남아 있던 작업일 수로 나눈 값입니다.
  저장해 두지 않고 매번 다시 계산하므로, **총 작업량을 고치면 입력한 실적은 그대로 둔 채
  모든 날의 목표량이 새 총량 기준으로 다시 잡힙니다.**
- 하루 쉬었다면 **0을 입력**하세요. 그 날짜가 남은 날에서 빠지면서 뒤로 재분배됩니다.

### 예시 (50컷 / 5일)

| 단계 | 25일 | 26일 | 27일 | 28일 | 29일 |
|---|---|---|---|---|---|
| 작업일 지정 직후 | 10 | 10 | 10 | 10 | 10 |
| 25일에 4컷 입력 | **4/10** | 12 | 12 | 12 | 12 |
| 26일에 0컷 입력 | 4/10 | **0/12** | 16 | 16 | 16 |

### 콘티 모드

프로젝트를 만들 때 **콘티**를 켜면 초안과 클린업이 각각 독립적으로 계산됩니다.
같은 작업일을 공유하지만 목표량과 실적은 따로 관리되므로, 초안만 앞서 나가거나
클린업이 밀리는 상황이 각각 반영됩니다. 캘린더에는 네 줄로 표시됩니다.

```
초안 목표    10
초안 작업    14 ✓
클린업 목표  11
클린업 작업   —
```

### 일정 옮기기

캘린더의 프로젝트 칩을 잡아 다른 날짜에 놓으면 일정이 옮겨집니다.

- **그냥 드래그** — 잡은 날짜에 **연달아 붙어 있는 작업일 전체**가 간격을 유지한 채 함께 이동합니다.
  (9/7~9/11 중 9/9를 잡아 9/14에 놓으면 → 9/12~9/16으로 이동)
- **Alt+드래그** — 잡은 **하루만** 옮깁니다. 묶음에서 하루를 빼내 다른 날로 보낼 때 씁니다.
- 이미 입력한 작업 기록도 날짜와 함께 따라갑니다.
- **마감일**은 옮기는 묶음에 마지막 작업일이 포함될 때만 같은 일수만큼 함께 이동합니다.
  앞쪽 일정만 조정하는 경우에는 마감일이 움직이지 않습니다. 드래그 중에 마감일이
  착지할 날짜가 주황색 `마감` 표시로 미리 보입니다.

작업일 지정 모드에서는 드래그가 꺼집니다. 터치 화면에서는 동작하지 않습니다.

## 타임테이블

왼쪽 사이드바 위쪽에서 **프로젝트 / 타임테이블** 탭을 전환합니다.

타임테이블 탭에서는 하루치 작업을 한 화면에서 처리합니다.

- **작업량 입력** — 그날 작업일로 지정된 프로젝트가 목표량과 함께 나열되고, 여기서 바로 컷수를 입력합니다.
  콘티 프로젝트는 초안·클린업 칸이 따로 나옵니다.
- **기록** — 입력할 때마다 **시각과 이번 입력분**이 남습니다.
  10컷이 들어 있는 칸에 20을 넣으면 `+10컷`으로 기록되고, 옆에 누적값이 함께 표시됩니다.
- **메모** — 기록 위의 입력칸에 글을 적고 Enter를 누르면 그 시각으로 메모가 남습니다.
  작업량 기록과 같은 목록에 시간순으로 섞여 표시되며, 컷수 합계에는 영향을 주지 않습니다.
- **수정 · 삭제** — 기록 줄에 마우스를 올리면 `✎`와 `✕`가 나옵니다.
  `✎`로 컷수를 고치고 `✕`로 그 기록을 지웁니다. 작업량 합계도 함께 조정됩니다.
- 입력칸의 숫자를 **줄이면** 마이너스 기록을 남기는 대신 **최근 기록부터 깎아 냅니다.**
  기록은 항상 `+` 값만 남고, 기록의 합은 그날 작업량과 항상 일치합니다.
- `‹ ›` 로 날짜를 옮겨 지난 날의 기록을 볼 수 있습니다.

캘린더 날짜를 눌러 입력해도 같은 기록에 남습니다. 기록은 백업 파일에 함께 저장됩니다.

### 하루의 기준은 오전 6시

자정이 아니라 **오전 6시부터 다음날 오전 6시까지**를 하루로 봅니다.
새벽 2시에 한 작업은 전날 몫으로 합산됩니다.
캘린더의 "오늘" 표시와 상단 합계도 같은 기준을 따릅니다.

## 화면

- 왼쪽 프로젝트 목록은 **이름만 접힌 상태**로 보입니다. 이름을 누르면 진행률·하루 목표·버튼이 펼쳐지고, 다시 누르면 접힙니다.
- 목록 오른쪽 위 `등록 · 색상 · 마감` 버튼으로 정렬을 바꿉니다.
  **등록**은 만든 순서, **색상**은 색상표 순서, **마감**은 마감일이 빠른 순(미지정은 맨 뒤)입니다.
  선택한 정렬은 저장되며 캘린더 안의 표시 순서에도 함께 적용됩니다.
- 캘린더는 무엇을 추가하거나 입력해도 **보고 있던 위치를 그대로 유지**합니다.
  다른 날짜로 이동하려면 위쪽의 `‹ ›` 또는 `오늘` 버튼을 쓰세요.
- 오른쪽 위 **오늘 목표 / 완료 / 남은** 합계는 콘티 프로젝트의 경우 **클린업만** 셉니다.
  초안은 합계에서 빠집니다. (프로젝트별 초안 진행률은 사이드바에서 그대로 볼 수 있습니다)

## 사용법

1. `index.html`을 브라우저로 엽니다. (설치·빌드 불필요)
2. 왼쪽 아래 **+ 새 프로젝트**로 이름·총 컷수·색상을 등록합니다.
   캘린더 날짜를 눌러 **+ 이 날짜 마감으로 새 프로젝트**를 선택하면 마감일이 미리 지정됩니다.
3. 저장하면 작업일 선택 모드로 들어갑니다. 캘린더에서 작업할 날짜를 하루씩 클릭하세요.
4. 매일 날짜를 눌러 그날 실제로 한 컷수를 입력합니다.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 화면 구조 |
| `style.css` | 스타일 (다크모드 자동 대응) |
| `app.js` | 계산 로직과 상태 관리 |

## 주간 체크리스트

캘린더 각 주의 맨 오른쪽 칸이 그 주의 체크리스트입니다.

- 칸 **맨 아래에 놓인 연한 네모**를 누르고 입력한 뒤 Enter를 누르면 항목이 추가됩니다.
  칸의 빈 곳을 아무 데나 클릭해도 바로 입력할 수 있습니다.
- 체크박스로 완료 표시, 글자를 클릭하면 바로 수정할 수 있습니다.
- 내용을 모두 지우거나 `✕`를 누르면 항목이 삭제됩니다.
- 왼쪽 **손잡이(⠿)를 잡고 드래그**하면 순서를 바꾸거나 다른 주로 옮길 수 있습니다.
  글자는 편집용이라 드래그되지 않으니 손잡이를 잡으세요.

## 백업

데이터가 브라우저 안에만 있어서, 브라우저 데이터를 지우면 기록이 사라집니다.
왼쪽 아래 버튼으로 백업을 관리하세요.

- **백업 내보내기** — 전체 데이터를 `웹툰작업량_백업_YYYY-MM-DD.json` 파일로 저장합니다.
- **불러오기** — 백업 파일을 읽어 복원합니다. **지금 있는 데이터는 모두 지워지고** 파일 내용으로 바뀌므로, 확인 창에서 개수를 보고 진행하세요.

다른 컴퓨터로 옮길 때도 이 방법을 씁니다. 내보낸 파일을 옮긴 뒤 그쪽에서 불러오면 됩니다.

## 주의

데이터는 브라우저별로 저장되므로 **기기 간에 자동 동기화되지 않습니다.**
다른 기기에서 열면 작업 기록이 보이지 않습니다. 옮기려면 위의 백업 기능을 쓰세요.
